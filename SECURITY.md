# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through GitHub's
private vulnerability reporting feature for this repository. Open the
repository's **Security** tab and select **Report a vulnerability** (or the
equivalent private reporting option).

Do not disclose a vulnerability in a public issue, pull request, discussion, or
other public channel. Include enough detail to reproduce the issue, including:

- the affected version, commit, or deployment;
- the affected route, component, or configuration;
- reproduction steps or a minimal proof of concept;
- the security impact; and
- any suggested mitigation, if known.

Please redact secrets, credentials, personal information, and production data
from the report. If the report contains sensitive material, attach it only to
the private GitHub report and do not include it in screenshots or logs shared
elsewhere.

## Response and disclosure

The maintainers will acknowledge receipt through the private GitHub report and
use that channel for follow-up, triage, and coordinated disclosure. Please
allow time for investigation and remediation before making details public.

Security reports are preferred over public issue reports even when the impact
appears limited; public issues may be used after maintainers confirm that no
sensitive details are involved.

## Scope

This policy covers the HacerPedido webapp and its repository-controlled
configuration. Reports about third-party services, dependencies, or the
underlying hosting provider should also be reported to their respective
maintainers when appropriate.
